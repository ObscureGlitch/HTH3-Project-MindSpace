# The Last Watch

Technical foundation for a short first-person forest-ranger horror game. Milestone 2 intentionally contains no environment, story, puzzle, scare, voice-service, or biometric-service implementation.

## Open the project

1. Open Unity Hub and add this repository as a project.
2. Use **Unity 6000.6.3f1** with the Windows Build Support module.
3. Let Package Manager restore the package versions recorded in `Packages/manifest.json`.
4. Open `Assets/_Project/Scenes/Bootstrap.unity` and enter Play mode.

The project targets 64-bit Windows and now uses **URP 17.6** for the therapy-room scene. `Bootstrap` is build scene 0 and loads `MainMenu` using the development configuration. The original foundational scenes remain technical shells.

## Therapy and wellness room

Open `Assets/_Project/Scenes/TherapyRoom.unity` and press Play to explore the room directly. Use WASD to walk, the mouse to look, E to notice interactive objects, and Esc to release the cursor. Press Enter to resume.

The room is approximately 7 × 6 × 3 metres, with an oak floor, sage accent wall, rounded upholstered seating, plants, a grounding shelf, breathing orb, and window reflection seat. All models and materials are generated locally; no paid or downloaded art assets are needed.

See [the room guide](Documentation/Wellness/RoomGuide.md) for asset locations, lighting, interaction hooks, and audio placeholders.

Remaining dependencies are Unity modules and URP dependencies. No Asset Store packages, networking frameworks, or external service SDKs are required.

## Configuration and secrets

Development and release settings are ScriptableObject assets under `Assets/_Project/Config`. They contain non-sensitive behavior flags only. The bootstrap scene currently references `GameConfiguration.Development.asset`; select the bootstrap object and swap the asset when preparing a release build.

Never store credentials in Unity assets, scenes, prefabs, scripts, or tracked JSON. When a future milestone adds a provider, supply secrets through local environment variables or a user-local file outside this repository, and keep only the variable names in documentation. Suggested future names are `TLW_ELEVENLABS_API_KEY` and `TLW_PRESAGE_API_KEY`; neither is read by Milestone 2.

## Validation

Use **The Last Watch > Validate Milestone 2** in the Unity editor, or run the edit-mode tests. The validator checks scene order, assets, action names, bootstrap references, target platform, and placeholder providers.

See [Architecture](Documentation/Architecture.md) and [Conventions](Documentation/Conventions.md) before extending the project.
